Only 30 held-out queries were evaluated. Pooled recall depends on the reviewed candidate pool, and these are benchmark-specific results—not a claim about all judgments or all legal questions.

WHAT DID NOT IMPROVE

Cross-encoder reranking did not improve upon Hybrid RRF in this evaluation. There was no independent legal validation.

04 / Engineering notes

Decisions made
measurable.

01

Hybrid retrieval was worth testing

Dense search captures semantic similarity while BM25 preserves exact legal terminology. RRF combines ranks without requiring incompatible score calibration.

02

RRF stays the leading baseline

Plain judgment-level Hybrid RRF recorded the strongest held-out point estimates. Reranking remains an independent experiment, not a default claim of improvement.

03

Splits protect interpretation

Development experiments and the frozen held-out retrieval benchmark are reported separately so tuning evidence is not presented as unseen-test evidence.

04

Local runtime, honest cloud edge

The full pipeline remains containerised locally because the verified AWS function is a lightweight metadata API, not a host for models, vectors, or generation.
